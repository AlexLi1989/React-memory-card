For this memory card project, it should display 20 images with name of image scrambled at a time, allows the user to click any image,if it is not clicked before, add one point and refresh all images, if all 20 images are clicked(all 20 points are scored) generate 20 new images and let the game continues. The game stops once user clicked a previous clicked image.

Once game over, a modal pops preventing all further interaction with the game, button with start new game should display on the modal.

There should be a scoreboard component that shows current score and highest score reached.

The chosen image api for this app is https://pokeapi.co/
